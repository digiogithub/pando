# Pando TUI Fixes Plan - 2026-03-08

## Identified Issues

### 1. Copilot API Error: "Unrecognized request argument supplied: reasoning_effort"
- **File**: `internal/llm/provider/copilot.go:285-296`
- **Root cause**: The `preparedParams()` method sends `reasoning_effort` for ALL models with `CanReason: true`. However, the GitHub Copilot API does NOT support this parameter for all models (e.g., GPT-5.4, Claude models via Copilot proxy).
- **Affected models**: GPT-4.1, o1, o3-mini, o4-mini, Claude 3.7 Thought, GPT-5.4, Claude Opus 4 - all have `CanReason: true`
- Copilot API only supports `reasoning_effort` for OpenAI o-series models (o1, o3-mini, o4-mini)

### 2. Help Panel without scroll and truncated content
- **File**: `internal/tui/components/dialog/help.go`
- **Root cause**: The `helpCmp` component renders all content directly without using a `viewport.Model` from bubbles. When content exceeds screen height, it is cut off.
- No max height (fixed height), no scroll, no navigation key handling (j/k, pgup/pgdn)

### 3. Inconsistent background colors
- **Files**: `help.go`, `styles.go`, overlay system
- **Root cause**: 
  - In `renderSection()`, the `helpKeyStyle` and `helpDescStyle` styles use `Regular()` (no default background) with `.Background(t.Background())`, but the space between elements has no background applied
  - The `baseStyle.Render(strings.Repeat(" ", ...))` on line 126 uses `BaseStyle()` which has a background, but horizontal joins with `lipgloss.JoinHorizontal` do not fill the background uniformly
  - The "Navigation" section and subsequent sections show a different background color because the content does not fill the full width of the panel

### 4. Missing Ctrl+i for file editing and Ctrl+s for saving
- **Files**: `internal/tui/keys.go`, `internal/tui/components/editor/tabs.go`, `internal/tui/tui.go`
- **Current state**: No keybindings exist for editing files in an external editor (Ctrl+i) or for saving (Ctrl+s is assigned to "switch session")
- Ctrl+s conflicts with switch session - needs reassignment
