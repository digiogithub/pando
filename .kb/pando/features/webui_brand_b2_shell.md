# WebUI brand B2 — shell (PANDO-US-0060, epic PANDO-EP-0011)

Part of [[pando-v1-brand-identity]] (epic PANDO-EP-0011, milestone PANDO-M-0003). Builds on the
BrandMark foundation from B1 ([[web-ui/src/components/brand/BrandMark.tsx]], `brand.css`,
`tokens.css` brand tokens — laid down by the lead before this story).

## What changed

**Favicon / PWA / manifest**
- `web-ui/index.html`: `<link rel="icon">` → `/favicon.svg` with `<link rel="alternate icon" href="/pando-icon.svg">` fallback; `apple-touch-icon` → `/apple-touch-icon.png`; `theme-color` meta → `#0c1f18` (new pando dark bg); no-FOUC boot script `bgs.pando` pair updated to `['#fdfcf8', '#0c1f18']` (mirrors tokens.css, verified by `check-contrast.mjs`).
- `web-ui/vite.config.ts`: PWA `includeAssets` now lists `favicon.svg`, `pando-icon.svg`, `apple-touch-icon.png`, `pwa-icon-192.png`, `pwa-icon-512.png` (dropped `pando_mascot.svg`, the old mascot). Manifest `theme_color`/`background_color` set to Bosque `#0F2A20` (fixed brand ink, not the family bg — matches the maskable icon's full-bleed background). Icon list unchanged (192/512/any + `pwa-icon-maskable.png` purpose `maskable`) — those files already exist under `web-ui/public/` (generated by the B4 packaging agent, confirmed present before this story finished).

**BrandMark replacing every 木 text glyph in this area**
- `src/components/layout/Header.tsx`: title bar `.shell-brand-glyph` now renders `<BrandMark size={18} pulse={busy} />` instead of a cycling kanji `<span>`. `shell.css` `.shell-brand-glyph` simplified (dropped the tinted 22px chip background/font styling — the mark is bare, `color: var(--fg)`).
- `src/components/chat/MessageList.tsx` (`ChatEmptyHead`): empty-chat mark is `<BrandMark size={40} className="chat-empty-mark" />`; greeting `<h1>` gets `.brand-display` (Space Grotesk). `chat.css` `.chat-empty-mark` reduced to just `color: var(--fg)` (old 44px tinted-chip/serif-glyph styling removed); added `.chat-empty-title.brand-display { font-weight: 600; letter-spacing: -0.01em }` — a compound selector so it always wins regardless of stylesheet import order (brand.css is pulled in via the BrandMark.tsx module graph, not index.css, so ordering vs. chat.css isn't guaranteed).
- `src/components/chat/SimpleChatView.tsx`: header `<img src="/pando-icon.svg">` → `<BrandMark size={18} />`; removed the now-dead `.chat-simple-brand img` CSS rule.
- `src/components/splash/SplashScreen.tsx`: mark is now `<BrandMark tile size={64} title="Pando" />` (app-icon tile form: fixed Bosque rounded square, drawn by BrandMark itself) instead of a 木 glyph in a tinted circle; wordmark `<div className="splash-wordmark brand-display">`. `splash.css` `.splash-mark` stripped of its own background/color/font (kept the pulse animation + added `box-shadow: var(--shadow-md)` so the tile reads as a raised icon); `.splash-wordmark` letter-spacing removed (brand-display supplies it), with a comment noting the dependency.
- `src/hooks/useDesktopNotifications.ts`: default `Notification` icon changed from `/pando-icon.svg` to `/pwa-icon-192.png` — `Notification.icon` has inconsistent SVG support across browsers.

**Busy indicator refactor**
- Deleted `src/hooks/useAnimatedLogo.ts` (cycled 本枝葉林森 in the title bar — confusing now that 本 is the Remembrances section mark). Grepped first: only `Header.tsx` imported it (no tests, no other area), so it was a clean rename rather than an additive change.
- Added `src/hooks/useAgentBusy.ts` — `useAgentBusy(): boolean`, same detection logic (`isStreaming || sessions.some(s => s.is_running)`). `Header.tsx` now does `<BrandMark size={18} pulse={busy} />`; the pulse animation (nodes pulsing, reduced-motion safe) lives in `brand.css` from the B1 foundation. TUI keeps its own text-cycling animation (different codebase, not in scope).

**`pando` theme family + `gold` accent aligned to the brand palette** (`src/styles/tokens.css`, `src/styles/themes.ts`)

Dark (Bosque-derived, deep green-black — tuned to read calm/premium, not saturated green):
```
--bg: #0c1f18   --bg-shell: #0a1a14   --bg-raised: #16332a
--bg-card: #0e2419   --bg-input: #0d221a   --bg-overlay: #132d22
--fg: #f4f1e8 (Marfil)   --fg-muted: #b6b2a2   --fg-faint: #8b887c
--border: #1c352b   --border-strong: #2a4238
--accent: #e9b949 (Álamo)   --accent-fg: #0f2a20 (Bosque)
```
Light (Marfil-tinted, Bosque-ink text):
```
--bg: #fdfcf8 (near-white ivory)   --bg-shell: #f4f1e8 (Marfil exact)   --bg-raised: #ece6d4
--bg-card/input/overlay: #ffffff
--fg: #10251c (Bosque-ink)   --fg-muted: #4b564e   --fg-faint: #707a71
--border: #e9e3d2   --border-strong: #d9d0b8
--accent: #8f6310   --accent-fg: #ffffff
```
The brand's literal Álamo oscuro `#C68A17` **fails** contrast as UI text/fill on this light bg
(white-on-#C68A17 = 2.98:1 < 4.5 required; #C68A17-on-bg = 2.90:1 < 3 required) — used `#8f6310`
instead (5.30:1 / 5.17:1), per the brief's explicit fallback instruction. All other checks pass
with comfortable margin (fg/fg-muted/fg-faint on bg/shell/raised, both modes).

`gold` accent preset realigned to the same two pairs (light `#8f6310`/`#ffffff`, dark
`#e9b949`/`#0f2a20`) so `data-accent="gold"` now literally *is* the brand accent, on every family
(re-verified contrast against paper/slate/forest bg's too — all ≥5:1 dark, ≥5:1 light).

Other families (paper/slate/forest) and other accent presets untouched.
