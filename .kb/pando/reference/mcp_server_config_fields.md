# Reference: MCP server configuration fields (`.pando.toml`)

Every field an entry under `[MCPServers.<name>]` accepts, which of them are optional, and which
transport actually uses them. Source of truth: `config.MCPServer` (`internal/config/config.go`)
and `config.MCPAuth` (`internal/config/mcp_auth.go`); machine-readable copy in
`pando-schema.json` (generated by `cmd/schema`).

Related: [[mcp_client_authentication]], [[mcp_mtls_enterprise_completion]],
[[mcp_client_auth_phase1_static]].

## Server-level fields

| Field | Type | Required | Applies to | Notes |
|---|---|---|---|---|
| `Type` | `"stdio" \| "sse" \| "streamable-http"` | Yes | all | Transport. Anything else fails with `unknown MCP server type`. |
| `Command` | string | stdio only | stdio | Executable to spawn. |
| `Args` | []string | Optional | stdio | Arguments for `Command`. |
| `Env` | []string | Optional | stdio | `KEY=value` entries. **This is where stdio credentials go**, per the MCP spec. |
| `URL` | string | sse / streamable-http | http | Server endpoint. |
| `Headers` | map[string]string | Optional | http | Extra HTTP headers. An entry here always **wins over** the header derived from `Auth` (`AuthHeaders` uses set-if-absent), so it can override a derived `Authorization`. |
| `Timeout` | string duration (`"30s"`, `"2m"`) | Optional | all | Per-operation timeout. Empty/invalid falls back to 30s for calls and 15s for discovery (`mcpclient.ResolveTimeout`). |
| `Auth` | table | Optional | http | Authentication/TLS block, below. Nil = pre-existing behaviour (nothing beyond `Headers`/`Env`). A non-`none` `Auth` on a **stdio** server is ignored with a warning. |

## `[MCPServers.<name>.Auth]` — application-level authentication

| Field | Type | Required for | Notes |
|---|---|---|---|
| `Type` | `none` (default) `\| bearer \| basic \| header \| oauth \| oauth_client_credentials` | — | Empty or absent = `none`. |
| `Token` | string | `bearer`, `header` | `bearer` sends `Authorization: Bearer <Token>`; `header` sends `Token` as the **raw** value (no prefix) of `HeaderName`. AGE-encrypted at rest. |
| `Username` | string | `basic` | Not encrypted (not a secret). |
| `Password` | string | Optional for `basic` | AGE-encrypted at rest. |
| `HeaderName` | string | Optional for `header` | Defaults to `Authorization`. |

### `[MCPServers.<name>.Auth.OAuth]`

Used by `Type = "oauth"` (interactive authorization-code + PKCE) and
`Type = "oauth_client_credentials"` (headless).

| Field | Type | Required | Notes |
|---|---|---|---|
| `ClientID` | string | Yes for `oauth_client_credentials`; optional for `oauth` | Empty on `oauth` triggers RFC 7591 dynamic client registration. A config-pinned ClientID is never auto-invalidated on `invalid_client`. |
| `ClientSecret` | string | Yes for `oauth_client_credentials` | AGE-encrypted at rest. |
| `Scopes` | []string | Optional | Requested scopes; step-up adds server-challenged scopes to this set. |
| `RedirectURI` | string | Optional | `oauth` only. Must be loopback with an explicit port. Default `http://127.0.0.1:19876/mcp/oauth/callback`. |
| `CallbackPort` | int | Optional | `oauth` only. Default `19876`. No-op for client_credentials. |
| `AuthServerMetadataURL` | string | Optional | Skips RFC 9728/8414 discovery and uses this AS metadata URL. |

## Transport-level TLS / mTLS (same `Auth` table)

Independent of `Type`: a server can require a client certificate **and** a bearer token.
Ignored by stdio. **TOML-only by design** — deliberately not exposed in TUI or Web UI.
All of it applies to the OAuth traffic too (discovery, DCR, token endpoint, refresh), not just
to tool calls.

| Field | Type | Default | Notes |
|---|---|---|---|
| `ClientCert` | path | — | PEM client certificate for mTLS. `~` and `$VAR`/`${VAR}` expanded. Must be set together with `ClientKey` or validation fails. |
| `ClientKey` | path | — | PEM private key matching `ClientCert`. |
| `ClientKeyPassword` | string | — | Passphrase for an encrypted key. Supports legacy RFC 1423 PEM (`DEK-Info`) **and** PKCS#8 `ENCRYPTED PRIVATE KEY` (PBES2: PBKDF2 HMAC-SHA1/224/256/384/512 or scrypt, with AES-128/192/256-CBC or DES-EDE3-CBC). AGE-encrypted at rest. |
| `CACert` | path | — | PEM CA bundle to trust for this server. **Added to** the system trust store. |
| `CACertExclusive` | bool | `false` | Trust only `CACert` (pinning) instead of merging with system roots. Requires `CACert`. |
| `TLSServerName` | string | — | Overrides the SNI / verification hostname. Use for servers reached by IP, internal alias or tunnel — keeps verification ON. |
| `MinTLSVersion` | `"1.2" \| "1.3"` | Go default | A `TLS` prefix is tolerated (`"TLS1.3"`). 1.0/1.1 rejected at load time (RFC 8996). |
| `MaxTLSVersion` | `"1.2" \| "1.3"` | Go default | For middleboxes that mishandle TLS 1.3. Must be >= `MinTLSVersion`. |
| `SkipTLSVerify` | bool | `false` | **Insecure**: disables certificate validation entirely. Logs a loud warning on every use. Prefer `CACert`/`TLSServerName`. |

## Encryption at rest

AGE-encrypted (`age1:` prefix, key in `~/.config/pando/age-keys/<keyset>/`): `Auth.Token`,
`Auth.Password`, `Auth.ClientKeyPassword`, `Auth.OAuth.ClientSecret`. Everything else —
usernames, header names, client IDs, file paths, booleans, TLS versions — stays in clear.
Certificate/key **file contents** are never read into the config or re-encrypted; only their
paths are stored.

## Worked example (enterprise gateway)

```toml
[MCPServers.corp]
Type    = "streamable-http"
URL     = "https://10.20.30.40/mcp"
Timeout = "60s"

[MCPServers.corp.Auth]
Type              = "oauth_client_credentials"
ClientCert        = "$CERT_DIR/client.pem"
ClientKey         = "$CERT_DIR/client-key.pem"   # PKCS#8 PBES2 is fine
ClientKeyPassword = "…"                          # AGE-encrypted on save
CACert            = "/etc/pki/corp-ca.pem"
TLSServerName     = "mcp.corp.internal"          # cert does not carry the IP
MinTLSVersion     = "1.2"

[MCPServers.corp.Auth.OAuth]
ClientID     = "pando-agent"
ClientSecret = "…"
Scopes       = ["mcp.read", "mcp.write"]
```

## Validation and failure modes

Config validation (`MCPAuth.Validate`) rejects at load time: only one of `ClientCert`/`ClientKey`
set; `CACertExclusive` without `CACert`; an unsupported/typo'd TLS version; `MinTLSVersion` above
`MaxTLSVersion`; `bearer`/`header` without `Token`; `basic` without `Username`;
`oauth_client_credentials` without `ClientID`+`ClientSecret`; an unknown `Type`.

Runtime errors worth recognising: `the ClientKeyPassword is probably wrong` (PBES2 unpadding
failed), `x509: certificate signed by unknown authority` (set `CACert`), `certificate is valid
for X, not Y` (set `TLSServerName`), and `requires authorization. Run: pando mcp login <name>`.
