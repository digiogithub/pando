## Scope update (2026-09-30): decision providers + specs

Changes to scope:

- **Router provider choice.** The router is no longer tied to Ollama. `modelAutoMode.router.provider` accepts `ollama`, `typesafe` or `custom`, with `baseURL`, an API key (encrypted, masked, with `$ENV` fallback) and extra headers.
- **Discovery.**
  - Ollama: discovery filters `/api/tags` to models whose `capabilities` contains `"decision"`. Verified live on 0.35.0: `tev1:0.8b` reports `["decision","tools","thinking","completion"]`.
  - Remote providers: discovery uses `GET {baseURL}/v1/models` and understands both `{models}` and `{data:[{id}]}` responses. Mixed catalogues are narrowed with a heuristic. When the provider has no listing endpoint, the model name is typed in as free text.
- **New story.** PANDO-US-0086 covers the decision providers: discovery, health checks, "Test connection" and pulling models.
- **Context budget.** `tev1:0.8b` loads with `num_ctx 2050`, so state truncation is now token-aware per provider (Ollama `num_ctx`, Jev 32K).
