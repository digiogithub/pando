Cancelled 2026-09-29 by decision of the maintainer. An extra LLM call per turn (or per session) has no clear advantage: Pando already persists sessions and events and exposes them through search (`search_events`, `hybrid_search_remembrances`), so prior context is recoverable without automatic `remember` extraction. The dead `MemoryAutoCapture` setting is handled in PANDO-US-0036. See `pando/analysis/grok-build-memory-pros-cons.md`.
