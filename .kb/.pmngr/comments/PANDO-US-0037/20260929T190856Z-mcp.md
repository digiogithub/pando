Cancelled 2026-09-29 by decision of the maintainer. Pando will not add a per-user memory store: memory hidden in the user profile is hard to locate and back up and is lost with the machine. When personal memory is needed, it lives in a personal repository, and a primary Pando running there launches Pando instances in other repositories as subagents to reach each project's own memory. Tombstone/audit forgetting is not worth its cost given jj history. See `pando/analysis/grok-build-memory-pros-cons.md`.
