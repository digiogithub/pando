# Pando v1 — Identidad

Símbolo: 木 (árbol) con 撇 y 捺 curvos y tres nodos de circuito — una raíz, muchos agentes.

## Colores
| Nombre        | HEX       | Uso                         |
|---------------|-----------|-----------------------------|
| Bosque        | `#0F2A20` | Fondo de marca / tinta      |
| Marfil        | `#F4F1E8` | Trazo sobre oscuro          |
| Álamo         | `#E9B949` | Acento / nodos sobre oscuro |
| Álamo oscuro  | `#C68A17` | Acento sobre claro          |

## Tipografía
- Space Grotesk 500–600 — wordmark y titulares (el wordmark va convertido a trazados)
- JetBrains Mono — TUI, código y etiquetas

## Archivos
- `pando-icon.svg` — icono de app (≥64 px)
- `pando-icon-small.svg`, `favicon.svg` — versión reforzada para ≤48 px
- `pando-mark-*.svg` — símbolo sin fondo
- `pando-logo-dark.svg` / `pando-logo-light.svg` — logotipo para fondo claro / oscuro
- `pando-logo-mono-*.svg` — monocromos
- `png/` — 16–1024 px · `pando.ico` (Windows) · `pando.icns` (macOS)

## Familia de símbolos
Mismo sistema (monolínea Marfil, nodos Álamo, fondo Bosque), cada sección con su carácter:

| Sección        | Carácter | Idea |
|----------------|----------|------|
| Pando          | 木 árbol | Una raíz, muchos troncos |
| Remembrances   | 本 raíz / libro | El trazo dorado en la raíz es la memoria guardada |
| Mesnada        | 众 multitud / séquito | El señor (nodo macizo) y su mesnada (nodos en anillo) |

Cada sección tiene su carpeta (`remembrances/`, `mesnada/`) con la misma estructura de archivos.
